SET UP ONCE

Tick your emulators. Press Launch.

Each emulator keeps its own settings, and NodeWatch reads them back to you in plain words before it starts. It checks the screen size and the connection first, so it never sits there looking busy while doing nothing.

FROM YOUR PHONE

Away from your PC? Run it from Discord.

Connect your own Discord bot and every instance gets a live card in your server. Check on it, pause it, restart the game or open an emulator with a slash command. Only accounts you link can use it.

/status /start /pause /reload /shield /open

Alerts arrive when something needs you, and stay quiet when it fixes itself.

SEE THE PAYOFF

Every march counted as it comes home.

Gold, food and ore by day, by instance, over a day, a week, a month or all time. The dashboard shows each march's return as a bar, so you can see when the next slot frees up.

AND THE REST

Start and stop each instance at set times. It opens the emulator for you when it needs to.

Updates itself

New versions install from inside the app, and only ones signed by NodeWatch.
